# Use-case card layout

## Layout

Each use-case card remains a single visual surface. On desktop, its content uses a two-column grid:

- The left column contains provider, profile, and daily-frequency fields stacked vertically.
- The right column shows the existing GHG and water SVG icons with their values stacked vertically.
- The existing detail toggle spans both columns below them.

No internal borders, panel backgrounds, or "Parameters" heading are added. The detail toggle retains its current appearance and behavior.

## Responsive behavior

On narrow screens, the three sections stack in source order: form, primary impacts, then detail toggle.

## Accessibility and sobriety

- Existing form labels remain unchanged.
- Primary-impact icons retain their localized title and accessible name because no visible criterion label accompanies them.
- The layout uses existing data and inline SVG icons, with no request, dependency, asset, or interactive control added.
